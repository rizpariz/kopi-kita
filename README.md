# Kopi dan Kita — Frontend

Bagian tampilan (frontend) dari aplikasi Kopi dan Kita, dibuat dengan Laravel Blade.

## Isi folder

- `resources/views/` — halaman-halaman aplikasi (template Blade)
- `public/css/` — stylesheet
- `public/js/` — script JavaScript
- `public/images/` — gambar
- `public/vendor/` — library pihak ketiga (Bootstrap, jQuery, font)

Catatan: template Blade ini dirender oleh backend Laravel, jadi tidak bisa dibuka langsung di browser tanpa backend-nya.
